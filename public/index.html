The Authorization token above is a long-lived login session (12 hours) — for a Power Automate flow that needs to run for longer, create a dedicated admin account just for this flow so its session can be refreshed independently of your own login.

  1. Go to make.powerautomate.com → Create → Automated cloud flow.
  2. Trigger: Microsoft Forms → When a new response is submitted → pick your form.
  3. Add step: Microsoft Forms → Get response details (Response Id from the trigger).
  4. Add step: HTTP → POST to the endpoint URL above, with the two headers above, and the JSON body above — filling each value from the form's dynamic content.
  5. Save, then submit a test response and confirm the person shows up in the Roster tab and gets the email.

This server must be reachable at a public HTTPS address for Power Automate to call it — a local laptop address won't work here.
